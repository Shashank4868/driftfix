        How it works
        
    Changelog in, verified pull request out. Every step is inspectable, and nothing is guessed.
    
      
    
      
    
        
    01 · Read
    Map the change
    Each breaking change becomes an entry in the change map: versions, dates, changelog and rewrite rules.
    
          
    OPENAI_PYTHON_V1 = Change(
    id="openai-python-v1",
    from_version="0.x",
    to_version=">=1.0",
    released="2023-11-06",
)
    
        
    02 · Find
    Find every call
    The code is parsed, and the API is followed through aliases, loops and comprehensions, not grepped.
    
          
    import openai as oa

r = oa.ChatCompletion.create(...)
for row in r["data"]:
    print(row["embedding"])
    
        
    03 · Fix
    Rewrite the syntax tree
    Edits land on the concrete syntax tree, so comments, quoting and formatting survive.
    
          
    -r = oa.ChatCompletion.create(
    +r = client.chat.completions.create(
    -r["choices"][0]["message"]
    +r.choices[0].message
    
        
    04 · Prove
    Test, then open the PR
    Your tests run before and after. If they don't pass, the patch is rolled back and nothing is opened.
    
          
    ✕ tests before   3 failed
✓ removed calls  0 left
✓ tests after    3 passed
✓ pull request   opened
    
      
    

      
    
        
    
          
    The same engine on the command line
    
          
    Run it in CI or on a laptop. It scans, patches, runs the repository's own tests, commits to a branch and writes the pull request.
    
          
    $ driftfix scan .
    $ driftfix run .
    $ driftfix run . --open-pr

        Security
        
    Built to be merged. Safe enough to let near production code.
    
      
    
      
    
        
    Pull requests only
    Driftfix works on its own branch and never pushes to a default branch. Your team reviews and merges.
    
        
    Rolls back on failure
    If tests that passed before the patch fail after it, the patch is discarded and no pull request is opened.
    
        
    Says what it didn't do
    Patterns it can't rewrite safely are listed under "Needs a human look", with file and line, never guessed.
